# Plan 260501-rx4-01: Default appsettings.json + Inno Setup install-once

## Objective

Ship a default `appsettings.json` with the runtime; preserve user customizations across upgrades.

## Tasks

### Task 1 — Author default config + wire into csproj

**Files:**
- `src/FlaUI.Mcp/appsettings.json` (new)
- `src/FlaUI.Mcp/FlaUI.Mcp.csproj` (add `<Content Include>` block)

**Action:**
1. Create `src/FlaUI.Mcp/appsettings.json` (UTF-8, JSONC):
   ```jsonc
   {
     // Kestrel listener for the MCP HTTP/SSE transports.
     // Change BindAddress to "0.0.0.0" to expose the server on the LAN.
     // CLI flags (--bind, --port) and FLAUI_MCP_Server__* env vars override these values.
     "Server": {
       "BindAddress": "127.0.0.1",
       "Port": 3020
     }
   }
   ```
2. Add to `FlaUI.Mcp.csproj` ItemGroup:
   ```xml
   <ItemGroup>
     <Content Include="appsettings.json">
       <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
     </Content>
   </ItemGroup>
   ```

**Verify:** `dotnet build src/FlaUI.Mcp/FlaUI.Mcp.csproj -c Debug --nologo -v minimal` succeeds; `appsettings.json` appears in `src/FlaUI.Mcp/bin/Debug/net8.0-windows/`.

**Done:** File present in build output, build green.

---

### Task 2 — InnoSetup install-once entry

**Files:** `src/FlaUI.Mcp/Setup.iss`

**Action:** Add a new line to the `[Files]` section (right after the existing wildcard copy on line 37):

```ini
Source: "{#MyAppSourceFolder}\appsettings.json"; DestDir: "{app}"; Flags: onlyifdoesntexist uninsneveruninstall
```

- `onlyifdoesntexist` — installer skips the file if `{app}\appsettings.json` already exists (preserves user customizations on upgrade).
- `uninsneveruninstall` — uninstaller does NOT delete it (the existing `[Code]` section asks the user about deleting `{app}` entirely; this is consistent with leaving config alone unless the user confirms full wipe).

The existing `Excludes: "appsettings.json"` clause on the wildcard line keeps the wildcard from copying it (and clobbering an existing one) — our new explicit `onlyifdoesntexist` entry is the authoritative one.

**Verify:** Manual review of the diff (we don't run ISCC inline). Compile happens on `dotnet publish` per the csproj target.

**Done:** Setup.iss has exactly one explicit appsettings.json [Files] entry with the right flags; existing Excludes clause preserved.
